⚙ Conexión y datos

Todo se guarda en tu Google Sheets mediante SheetDB.

Usa tu misma API añadiendo ?sheet=Partidos. Déjalo vacío para guardar el historial solo en este dispositivo.

Qué debe tener la pestaña Partidos (1 minuto)
  1. En el mismo Google Sheets crea una pestaña llamada Partidos (si aún no existe).
  2. En la fila 1 escribe exactamente: id, jornada, fecha, data.
  3. No hace falta crear otra API: no toques la URL de la plantilla. La app usa la misma URL con ?sheet=Partidos.

Cada acta se guarda como un JSON en la columna data. No edites esa columna a mano; usa el botón ✏️ del historial.

Avanzado: API de actas independiente

Solo si publicaste el historial como una API aparte. Si está vacío, se usa la pestaña de arriba con la misma API.
